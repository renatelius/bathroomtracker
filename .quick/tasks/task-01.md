# Task-01 — Дизайн-спека: календарь прогноза + будильник

**Проект:** BathroomTracker — React Native Expo (SDK 54), plain JS.
Файлы контекста: `src/screens/PredictScreen.js`, `src/screens/HistoryScreen.js`,
`src/screens/LogScreen.js`, `src/model/model.mjs`.

## Цель
Написать готовую к внедрению дизайн-спеку (UX + цветовая палитра + тексты на русском)
для двух новых экранов: **«Календарь»** (визуализация дефекаций, приёмов пищи и дня
прогноза следующей дефекации) и экрана **«Будильник/Напоминание»** (настройка
локального уведомления в момент прогноза). НЕ пиши код — только спека, которую
opencode превратит в компоненты.

## Контекст модели
`predict()` возвращает `predictedAtMs`, `lowMs`, `highMs` (окно достоверности),
`factors`. Календарь должен показывать: дни с записями (дефекация / еда),
**день прогноза** (predictedAt) акцентно, и **диапазон дня low..high** мягкой
подсветкой. Будильник ставит уведомление на predictedAtMs.

## Что вернуть (текстом в чат + файлом в .quick/results/task-01/)

1. **Цветовая палитра** (hex-коды): фон, карточки, акцент, «прогноз», «окно
   достоверности», «дефекация», «еда», «тревога/будильник». Согласуй с уже
   используемым акцентом `#2f6fed`.
2. **UX-схема экрана «Календарь»**: структура (заголовок, сетка месяцев,
   маркировка дней, легенда), что показывать по нажатию дня, жесты.
3. **UX-схема экрана «Будильник»**: поля (время, за сколько до прогноза),
   переключатель «точное / приблизительное», состояния разрешений Android,
   обработка отказа, предупреждения.
4. **Русские тексты**: подписи, пустые состояния, ошибки разрешений,
   уведомления (заголовок + body), кнопки. Кратко и дружелюбно.
5. **Icon-намерения**: какие простые иконки нужны (эмодзи ok, но лучше описать
   назначение) — я добавлю их в код.
