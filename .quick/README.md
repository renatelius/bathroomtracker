# Мост Amazon Quick (ручной канал 4-го агента) — BathroomTracker

Amazon Quick — ИИ-ассистент в десктоп-приложении или веб-версии https://quick.aws.com.
У него нет CLI/API, поэтому opencode не вызывает его напрямую: задания передаются
через эту папку, а результаты возвращаются сюда же.

## Поток работы (кратко)

1. **opencode** пишет задание: `.quick/tasks/task-NN.md` (краткое ТЗ + что вернуть).
2. **Вы** открываете Amazon Quick и вставляете содержимое файла `task-NN.md` в чат
   (или перетаскиваете файл). Помощник выполняет: код, изображения, тексты, идеи.
3. **Вы** сохраняете результат:
   - код — прямо в рабочую копию проекта `B:\Проекты\BathroomTracker` (в нужные файлы),
   - изображения — в `assets/` (с понятным именем),
   - текст/отчёты/дизайн-спеки — в `.quick\results\<task>\`.
4. **Вы** пишете opencode: «task-NN готово». opencode проверяет изменения,
   правит интеграцию, подключает результат и при необходимости коммитит.

## Формат задания (шаблон task-NN.md)

- **Цель**: что именно сделать (1–3 фразы).
- **Контекст**: ссылки на файлы/папки (`src/screens/`, `src/model/model.mjs`, `assets/`).
- **Ограничения**: стиль проекта (React Native Expo SDK 54, plain JS, ESM-ядро).
- **Формат результата**: куда сохранить (пути), что вернуть в чат.

## Правила

- Каждое задание = свой файл в `.quick/tasks/`, результаты — в `.quick/results/<task>/`.
- Папка `.quick/` НЕ уходит в git (в `.gitignore` уже добавлена).
- Генерацию изображений указывайте в ТЗ явно: «создай изображение ... и сохрани в assets/».
- Если Amazon Quick предложит многошаговое решение — дайте ему выполнить и принесите итог.
