# Bristol Cover — Art Brief / Design Doc

> Владелец: агент **картинок** (арт-дирекшн + PNG-ассеты).
> Назначение: макет обложки функции «Детальный экран Бристоля» для README и промо.
> Реализация: opencode генерирует PNG/SVG по этому брифу (node, Canvas/SVG-подход, как `make_icons2.js`).
> НЕ трогает код приложения (screens/ui/i18n — другие агенты).

## 0. Токены дизайн-системы

### Палитра (hex)

| Токен | Hex | Назначение |
|---|---|---|
| `brand.primary` | `#2563EB` | Старт фонового градиента (синий) |
| `brand.accentCyan` | `#38BDF8` | Финиш фонового градиента (голубой) |
| `brand.badge` | `#FFFFFF` | Заливка круглых badge под глифы |
| `state.success` | `#22C55E` | **Акцент типа 4 «норма»** |
| `text.onDark` | `#FFFFFF` | Заголовок и подписи на градиенте |
| `text.onDarkMuted` | `#DBEAFE` | Вторичный текст / подзаголовок |
| `text.onBadge` | `#1E293B` | Цифры/глифы внутри белого badge |
| `shadow.soft` | `rgba(2, 6, 23, 0.25)` | Мягкая тень под badge и заголовком |
| `hairline` | `rgba(255,255,255,0.16)` | Тонкие разделители / орбита-линия |

### Градиент фона

- Тип: линейный, направление **135°** (сверху-слева → снизу-справа).
- Stops: `0% #2563EB` → `100% #38BDF8`.
- Поверх — лёгкий радиальный «glow» из центра: `rgba(255,255,255,0.10)` радиусом ~45% ширины, для объёма (опционально).

### Контраст (WCAG AA)

- `#FFFFFF` на `#2563EB`: контраст ≈ 5.17:1 → **AA для крупного и обычного текста**. ✅
- `#FFFFFF` на `#38BDF8` (светлый край): контраст ≈ 1.8:1 → **недостаточно**.
  → Правило: **весь текст размещать в левой/центральной тёмной зоне** (над #2563EB), либо подкладывать полупрозрачную плашку `rgba(15,23,42,0.28)` под текст на светлом крае.
- `#1E293B` на `#FFFFFF` badge: ≈ 13.6:1 → **AAA**. ✅
- `#22C55E` используется как заливка/обводка акцентного badge, НЕ как текст на градиенте (для текста зелёный на синем недостаточно контрастен).

### Типографика

- Заголовок: **Inter / SF Pro / system-ui**, вес **800**, tracking `-1%`.
  - Строка: `BathroomTracker · Bristol` (разделитель — middle dot `·`).
  - Слово `Bristol` — вес 800, цвет `#FFFFFF`; `BathroomTracker ·` — вес 700, цвет `#DBEAFE`.
- Подзаголовок: Inter/SF Pro, вес **500**, `#DBEAFE`: `Bristol Stool Scale · типы 1–7`.
- Цифры внутри badge: Inter, вес **700**, `#1E293B`.

## 1. Семь глифов (типы 1–7 шкалы Бристоля)

Каждый глиф — стилизованная пиктограмма в белом круглом badge (`brand.badge`), диаметр по раскладке ниже. Глиф рисуется цветом `text.onBadge` (`#1E293B`), кроме **типа 4**, который выделен `state.success` (`#22C55E`).

| Тип | Смысл | Пиктограмма (Canvas/SVG-описание) | Цвет глифа | Badge-обводка |
|---|---|---|---|---|
| 1 | Отдельные твёрдые комочки | 3–4 маленьких раздельных круга (r≈6% badge) в ряд | `#1E293B` | нет |
| 2 | Колбаса, но комковатая | толстый «бугристый» валик (rounded-rect с волной по контуру) | `#1E293B` | нет |
| 3 | Колбаса с трещинами | валик с 2–3 короткими насечками-трещинами сверху | `#1E293B` | нет |
| **4** | **Норма (гладкая, мягкая)** | **гладкий изогнутый валик (плавный S/дуга), скруглённые концы** | **`#22C55E`** | **кольцо 3px `#22C55E` + мягкий glow** |
| 5 | Мягкие капли с чёткими краями | 3 округлые капли раздельно | `#1E293B` | нет |
| 6 | Рыхлые кусочки, рваные края | «облачко» с зубчатым/рваным контуром | `#1E293B` | нет |
| 7 | Жидкий, без твёрдых частиц | волнистая заливка нижней трети badge + пунктир-рябь | `#1E293B` | нет |

**Акцент на тип 4:** badge крупнее остальных на ~15%, кольцо `#22C55E` (3px), мягкое свечение `0 0 16px rgba(34,197,94,0.45)`, под ним микро-лейбл `норма` (Inter 600, `#FFFFFF`, на плашке `rgba(15,23,42,0.30)`).

## 2. Варианты макета

### (а) Hero-баннер / og-image — 1200 × 630

**Слои (снизу вверх):**

1. **BG**: линейный градиент 135° `#2563EB→#38BDF8` + опциональный центральный glow.
2. **Орбита** (декор): тонкая дуга `hairline` в правой части, вдоль которой раскладываются badges.
3. **7 badges** — раскладка «дуга/строка» в правой половине (x: 620–1140):
   - Диаметр обычного badge: **116 px**; тип 4: **134 px**.
   - Раскладка: горизонтальная лёгкая дуга в 2 «уровня» — типы 1,2,3 верхний ряд; 5,6,7 нижний ряд; **тип 4 — по центру между рядами**, крупнее и вынесен вперёд (наложение поверх соседей с тенью `shadow.soft`).
   - Под каждым badge — номер типа (Inter 700, `#1E293B` уже внутри badge как маленькая цифра в углу, r≈18px белый суб-кружок).
4. **Текстовый блок** (левая тёмная зона, x: 80–560, вертикально по центру):
   - Заголовок `BathroomTracker · Bristol` (72–80 px, вес 800, `#FFFFFF`; префикс `#DBEAFE`).
   - Подзаголовок `Bristol Stool Scale · типы 1–7` (28 px, `#DBEAFE`).
   - Микро-строка `Детальный экран · норма = тип 4` (20 px, `#DBEAFE`).
5. **Safe-margins**: 64 px со всех сторон; текст не заходит на светлый правый край.

### (б) Квадратная карточка — 1024 × 1024

- BG: тот же градиент 135°.
- Композиция вертикальная и центрированная:
  1. **Верх (0–34%)**: заголовок в 2 строки — `BathroomTracker` (`#DBEAFE`, 56px/700) над `Bristol` (`#FFFFFF`, 92px/800).
  2. **Центр (34–82%)**: 7 badges раскладкой **3-1-3** (ряд из 3 типов 1-2-3, по центру крупный **тип 4**, ряд из 3 типов 5-6-7). Диаметр обычного **150 px**, тип 4 **176 px** с зелёным кольцом и glow.
  3. **Низ (82–100%)**: подпись `Bristol Stool Scale · типы 1–7` (30px, `#DBEAFE`), по центру.
- Safe-margins: 72 px.

### (в) Мини-бейдж — 512 × 512 (и версия-фавикон 256)

- BG: градиент 135° со скруглением углов (radius 22% для «squircle» вида).
- Один крупный центр-глиф: **только тип 4** (`#22C55E`) в белом badge (диаметр ~62% полотна), с зелёным кольцом и glow.
- Без текста (или крошечная точка-акцент). Читается на 32–48 px.
- Экспорт: `512` (промо), `256` (favicon-подобный).

## 4. Правила рендера (для opencode)

- Рисовать в порядке: BG-градиент → glow → орбита/hairline → обычные badges (1,2,3,5,6,7) → **тип 4 поверх** → текст.
- Тени: `shadow.soft` = смещение `0 8px 24px rgba(2,6,23,0.25)` под каждым badge; тип 4 дополнительно зелёный glow.
- Антиалиасинг включён; экспорт PNG с прозрачностью НЕ нужен (фон сплошной градиент), кроме мини-бейджа squircle — там прозрачные углы.
- Шрифты: system-ui стек; если нужен фиксированный — Inter (Regular/500/700/800).
- Экспортные файлы (предложение путей, финально — на усмотрение opencode):
  - `assets/promo/bristol-hero-1200x630.png`
  - `assets/promo/bristol-card-1024.png`
  - `assets/promo/bristol-badge-512.png`
  - `assets/promo/bristol-badge-256.png`
